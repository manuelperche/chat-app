## Chatter

Real-time chat app with authentication, message history, online/offline status and image sharing. Built with React.js, Typescript, Tailwind CSS, Express.js, Socket.io, MongoDB and Cloudinary.

## 🚀 Getting Started

### Prerequisites

- Node.js 18.0 or later
- npm or yarn or pnpm

### Installation

1. Clone the repository

```bash
git clone https://github.com/manuelperche/chat-app.git
cd chat-app
```

2. Install dependencies

```bash
npm install
# or
yarn install
# or
pnpm install
```

3. Start the development server

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```
